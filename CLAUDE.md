# King's Field II, taken apart and ported

Before any work here, read [AGENT.md](AGENT.md): what may be committed (the
repository is public, history included), the method, what counts as done, and
the traps already paid for. Then FORMATS.md, BACKLOG.md and TOOLS.md as the
task needs them.

## The port and the game, one to one — always

Every function in `godot/` carries, in the comment block directly above it,
either what code of which executable it reproduces

```gdscript
# @orig game:0x8004e928 actor_turn  status:transcribed
func turn(a: Dictionary, target: int, most: int, accel: int) -> void:
```

-- one line per routine, or per stretch inside one, under the symbol table's
name, with how far it was checked (`verified` and the count, `transcribed`,
`partial` and what is missing, `guessed`) -- or that the game has no
counterpart, and which kind of the port's own code it is:

```gdscript
# @port engine -- runs _pass at the game's 15 frames a second
func _process(dt: float) -> void:
```

(`engine`, `data`, `check`, `helper`). Every address in a comment names its
executable: `# @exe game` once in a file's header, `open:0x80013a20` for an
address from another one.

**When you add or change a function in `godot/`, add or change its marker in
the same edit.** When you find that the port and the game disagree, say so in
the marker (`partial`, and what differs) and in BACKLOG.md.

`python3 tools/portmap.py --check` must pass before anything is called done.
To go from one side to the other:

```
python3 tools/portmap.py godot/ai.gd:turn     what in the game this function is
python3 tools/portmap.py game:0x8004e928      what in the port copies this code
python3 tools/rdis.py game 0x8004e928         the listing, with the port's lines in it
python3 tools/portmap.py --progress           how much of the game the port has, and
                                              what moved since data/progress.json
```

`portmap.py` prints a `progress:` line every run; when a commit moves it, say
in the report (in Russian) what it was and what it is now, and commit the
`data/progress.json` that `--doc` writes. What waits for a person -- a look in
the port, a session to record in the emulator -- goes into PLAYTEST.md (in
Russian) in the same commit as the finding.

The full rule is AGENT.md, "The port and the game, one to one"; PORT.md is the
whole table, regenerated by `python3 tools/portmap.py --doc`.
