# The port, against the game

Generated by `tools/portmap.py --doc`. Do not edit it: the markers
are in the GDScript itself, which is the only place they can stay
true when the code moves. The rules are in `tools/portmap.py`'s
docstring and in AGENT.md, "The port and the game, one to one".

**Every function in `godot/` says what it is.** One that reproduces
code of the game names the executable, the address and the routine:

```gdscript
# @orig game:0x8002ed60 player_vertical  status:verified 48/48 bp15
func vertical_step(y: int, surface: int) -> int:
```

and one with no counterpart in the game says which kind of the
port's own code it is:

```gdscript
# @port engine -- builds the level's nodes; the game has no scene graph
func _ready() -> void:
```

`tools/rdis.py game 0x8002ed60` prints the same pairing from the
other side, as a `; port:` line at the top of the listing, and
`tools/portmap.py game:0x8002ed60` / `tools/portmap.py
godot/player.gd:vertical_step` answer either question directly.

**A marker is a claim that the port reproduces that code, not
that it reproduces it correctly.** `status` says how far that went:

* **verified** — checked against a recording of the game, with a count
* **transcribed** — read off the MIPS, not yet checked against the game
* **partial** — part of the routine only; the note says which part
* **guessed** — neither read nor checked -- a placeholder

and `@port` says which kind of the port's own code a function is:

* **engine** — Godot's side: nodes, meshes, materials, input plumbing, timing
* **data** — reads what the tools wrote; the tool is where the game was read
* **check** — the self-test, the side-by-side comparison, the debug views
* **helper** — arithmetic the CPU did without being asked, small utilities

## How much is covered

671 functions in 39 files: **378 reproduce
code of the game** and 293 are the port's own
(84 check, 23 data, 56 engine, 130 helper). 436 markers, 844 addresses cited in
comments, every one of them with its executable.

| executable | routines | with a marker | stretches marked inside them | instructions | covered |
| --- | --- | --- | --- | --- | --- |
| boot | 10 | 1 | 1 | 115 | 50 (43%) |
| open | 293 | 9 | 3 | 20002 | 1607 (8%) |
| game | 820 | 229 | 155 | 93512 | 47193 (50%) |
| end | 167 | 0 | 0 | 9966 | 0 (0%) |

Those percentages are of *all* the code in the image, which includes
the Sony library, the CD reader and the memory card. They are a
floor, not a score.
